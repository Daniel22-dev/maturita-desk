# Historical pre-1.0.4 audit and stage evidence

This directory preserves Stage, QA and release-status artifacts from 0.x through
1.0.3 for traceability and regression context.

They are **not current release evidence** for Maturita Desk 1.0.4. Current GREEN
decisions must use the actual source revision, active GitHub Ruleset and current
successful P5 / Safe Promotion / deploy / live-verification evidence.

Selected historical summaries are intentionally read by current validation as
regression fixtures—for example, to ensure the project does not falsely claim
physical-device execution or a live school server. Their historical version
fields are not the current app version.
