MATURITA DESK 0.10.1 — STAGE 13R — INTERNÍ LOKÁLNÍ REVIZE REÁLNÉHO OBSAHU
============================================================================

ÚČEL
- Stejný balík lze bezpečně nahrát na veřejný GitHub a současně lokálně použít k interní revizi reálného obsahu.
- Na localhostu/loopbacku dovolí import klasifikace CONFIDENTIAL-EXAM.
- Na jiné adrese, včetně daniel22-dev.github.io, zůstává synthetic-only gate aktivní.
- Reálný .mdesk ani jeho přístupová fráze nejsou součástí tohoto ZIPu.

SPUŠTĚNÍ VE WINDOWS
1. Rozbalte celý ZIP do běžné lokální složky.
2. Dvojklik na START-MATURITA-DESK-INTERNAL.cmd.
3. Otevře se výchozí prohlížeč na http://127.0.0.1:8765/.
4. V aplikaci: Content Pack -> Importovat Content Pack...
5. Vyberte samostatně uložený neveřejný Maturita-Desk-AJ-2027-interni-revize-2027.0.1.mdesk.
6. Přístupovou frázi použijte z odděleného souboru.

DŮLEŽITÉ
- Reálný Content Pack ani přístupovou frázi nikdy nenahrávejte do veřejného GitHub repozitáře ani GitHub Pages.
- Neposílejte pack studentům.
- Obsah 2027.0.1-review je interní kandidát a ještě není pedagogicky schválen.
- Pilotní poznámky nevyplňujte textem ostrých zadání; zapisujte jen technické/UX nálezy.
- Okno lokálního serveru ponechte otevřené po dobu testu; zavřením se server vypne.
