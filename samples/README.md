# Synthetic Content Pack sample

Soubor `synthetic-demo-2027.mdesk` obsahuje výhradně syntetická demonstrační data z veřejného shellu.

Testovací heslo: `DEMO-ONLY-2027`

Toto heslo je záměrně veřejné, protože sample neobsahuje ostré ani neveřejné maturitní materiály. Pro skutečný Content Pack se heslo nikdy nesmí ukládat do repozitáře ani předávat na příkazové řádce; build nástroj používá proměnnou prostředí `MATURITA_DESK_PACK_PASSPHRASE`.
