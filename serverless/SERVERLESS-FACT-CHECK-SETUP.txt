MATURITA DESK 1.0.1 - SERVERLESS VERIFY / LOOKUP
================================================

The PWA can run without a school server. Only online Verify / Lookup needs a
small protected serverless endpoint.

PREFERRED DEPLOYMENT
--------------------
Use a SAME-ORIGIN endpoint on the isolated Maturita Desk host, for example:

  /api/fact-check

This keeps the browser CSP at connect-src 'self' and avoids introducing another
trusted browser origin.

SERVER-SIDE REQUIREMENTS
------------------------
- OPENAI_API_KEY secret;
- FACTCHECK_ACCESS_TOKEN for the temporary pre-SSO teacher mode, OR a future
  FACTCHECK_GATE_TOKEN for the school-server inner-gate mode;
- FACTCHECK_RATE_LIMITER;
- ALLOWED_ORIGINS set to the exact isolated Maturita Desk origin;
- optional OPENAI_FACTCHECK_MODEL.

PRIVACY BOUNDARY
----------------
The browser sends only the explicitly typed query. Exam topic, Teacher
Guidance, Notes, Content Pack and student identity are not attached.

UNTIL DEPLOYED
--------------
The public release intentionally keeps factCheck.endpoint empty. Exam, Practice,
Notes, Content Pack and offline use remain fully functional.
