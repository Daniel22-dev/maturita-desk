MATURITA DESK 1.0.1 - ORIGIN-NEUTRAL SERVERLESS DEPLOYMENT
==========================================================

GOAL
----
Maturita Desk remains in the GitHub repository Daniel22-dev/maturita-desk and
can be used both as a standalone PWA and as an application launched from AI
Studio. No school domain is required.

PUBLIC GITHUB PAGES ROLE
------------------------
https://daniel22-dev.github.io/maturita-desk/

This shared origin is a public/demo shell. It deliberately does not accept
CONFIDENTIAL-EXAM content.

ISOLATED PRODUCTION ROLE
------------------------
The final serverless app may be deployed to any chosen isolated HTTPS origin.
The source code does not hard-code that address. Instead, the exact origin is
authorized by a signed public file:

  config/origin-authorization.json

The signed file is bound to the exact HTTPS origin and the environment id. It
may be public and may be committed to GitHub. The signing private key must stay
off GitHub.

This means the production address can be selected later without another source
code release. Only the signed origin-authorization file has to be generated for
that address.

CONFIDENTIAL CONTENT
--------------------
A CONFIDENTIAL-EXAM pack is accepted only when all of the following are true:
1. the current host is localhost for controlled development, OR it has a valid
   signed origin authorization grant;
2. the grant explicitly allows confidential content;
3. the .mdesk has a valid publisher signature;
4. the user enters the correct pack passphrase.

NORMAL TEACHER WORKFLOW
-----------------------
Open the HTTPS PWA -> unlock/import the approved signed .mdesk -> work.
No .cmd file, local terminal or school server is required.

FACT CHECK / VERIFY-LOOKUP
--------------------------
The core application works without the online service. When enabled, a
same-origin endpoint such as /api/fact-check is preferred because it keeps the
PWA CSP narrow. OpenAI credentials remain server-side only.
